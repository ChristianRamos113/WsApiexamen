# Scripts de Base de Datos (SPE)

Esta carpeta contiene los Stored Procedures utilizados en el proyecto **WSAPIEXAMEN**.

## Contenido
- `SP_Insert_Examen.sql` → Inserta registros en la tabla Examen.
- `SP_Update_Examen.sql` → Actualiza registros existentes.
- `SP_Delete_Examen.sql` → Elimina registros.
- `SP_Select_Examen.sql` → Consulta registros.

Asi como script de la base y de la TableExamen
## Uso
Ejecutar los scripts en el orden indicado para inicializar la base de datos.
